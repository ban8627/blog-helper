# blog-helper

블로그 도우미 만들기 연재(네이버 블로그 banssa)에서 바이브 코딩으로 만드는 블로그 글쓰기 도구입니다.

## 1편 · 블로그 글자수 세기

- 바로 쓰기: https://ban8627.github.io/blog-helper/
- 글을 붙여 넣으면 공백 포함·공백 제외 글자 수, 단어 수, 내용이 있는 줄 수와 목표까지 남은 글자 수를 보여 줍니다.
- 입력한 글은 서버로 보내거나 브라우저에 저장하지 않습니다.
- 파일: `index.html`, `style.css`, `counter.js`(계산), `app.js`(화면). 빌드 도구·외부 라이브러리 없음.
